# Zabava

App mobile iOS et Android pour suivre ses films, séries et animés.

| Dossier | Contenu |
|---|---|
| `mobile/` | App Expo (React Native + TypeScript) |
| `backend/` | API Spring Boot 3 (Java 21) |
| `supabase/` | Configuration locale et migrations SQL |
| `specs/` | Spécification produit et technique |

## Démarrer l'app mobile
```
cd mobile
npm install
npx expo start
```

Les consignes de développement sont dans `CLAUDE.md`, le plan de travail dans `specs/etapes/`.
